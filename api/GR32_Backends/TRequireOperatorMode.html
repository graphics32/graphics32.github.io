TRequireOperatorMode

Enumeration specifying logical operator mode when matching backend interface requirements.

Declaration ​

pascal
TRequireOperatorMode = (romAnd, romOr);

Description ​

TRequireOperatorMode specifies whether all required interface GUIDs must be supported (romAnd) or if supporting any single interface is sufficient (romOr) when calling RequireBackendSupport.

Values ​

ValueDescription
romAndAll interface GUIDs must be supported by the backend.
romOrAt least one specified interface GUID must be supported by the backend.
